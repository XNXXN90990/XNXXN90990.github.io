## 为什么要写博客

写博客是一种「把学到的整理出来」的好方式。能写出来说明真的懂了，写不出来的往往是自己没弄明白。

## 步骤

1. 在 `docs/<分类>/` 目录下新建 `.md` 文件
2. 在文件头写上 `title` 和 `date`
3. 在 `docs/.vitepress/config.mts` 的 `sidebar` 中登记文章
4. 推送到 GitHub 触发自动部署

## 这个站点的写作约定

- 标题用句子首字母大写，避免「！」和过度的形容词
- 代码块指定语言，方便高亮
- 长文拆小节，每节不超过一屏
- 配图放在 `docs/public/` 下，引用用 `/xxx.png` 这种站根路径
