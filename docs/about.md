# 关于本站

欢迎来到我的小站。

这里是我在互联网上的一小块自留地，主要放四类内容：**学习路线**、**技术教程**、**随笔杂谈**，以及顺手收藏的**工具与资源**。

## 为什么做这个站

做这个站的念头来自两个前辈站点：[CS 自学指南](https://csdiy.wiki/) 和 [IC 自学指南](https://crys-chen.github.io/ic-guide/)。它们把各自领域的学习路径梳理得清清楚楚，毫无保留地分享给了所有人。这种认真整理、赠予后来人的精神打动了我，于是我也想把自己学到的东西整理出来，留在互联网上。

## 这个站想做什么

一是**记录**，平时学习、折腾的点滴，顺手记下来；二是**教程**，踩过的坑写成教程，别人就不用再踩一遍；三是**学习路线**，把熟悉的领域整理成体系化的指引，希望能给刚入门的朋友一点参考。

## 技术说明

本站使用 [VitePress](https://vitepress.dev/) 构建，托管于 GitHub Pages，支持日间/夜间模式切换与全文搜索。访问量统计由[不蒜子](https://busuanzi.ibruce.info/)提供，评论区基于 [giscus](https://giscus.app/zh-CN)（无需登录即可阅读评论）。站点还支持[私密文章](/tutorials/how-to-hide)：正文构建时加密，只有知道访问编号或标题的人才能找到并解锁阅读。如果你也想搭一个类似的站点，可以参考教程区的[《如何在这个站点写一篇文章》](/tutorials/how-to-write)。
