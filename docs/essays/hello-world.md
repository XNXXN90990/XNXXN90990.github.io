# 写在开篇：为什么我想做这个网站

前段时间偶然读到两个网站，一个是北大学生整理的 [CS 自学指南](https://csdiy.wiki/)，另一个是 [IC 自学指南](https://crys-chen.github.io/ic-guide/)。它们把各自领域的学习路径梳理得清清楚楚，毫无保留地分享给了所有素不相识的后来人。

读完之后我久久不能平静。原来一个人认真整理出来的东西，真的可以照亮这么多人的路。

于是我想，我也可以做点什么。

这个小站打算放三类东西。一是**记录**，平时学习、折腾遇到的人和事，顺手记下来，既是给自己的备忘录，也是生活的痕迹。二是**教程**，踩过的坑总结成经验，如果能写成教程，别人就不用再踩一遍。三是**学习路线**，像上面两个网站那样，把我熟悉的领域整理成体系化的路线，希望能给刚入门的朋友一点参考。

网站刚刚搭起来，内容还很空。不过没关系，慢慢来，一点点填。

> 不积跬步，无以至千里。

希望若干年后再回头看，这里已经长成了一片小小的树林。
