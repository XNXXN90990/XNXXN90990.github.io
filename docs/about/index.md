你好，我是 DBD。

学校智能车项目成员，业余时间会写一些教程、整理学习路线、记点生活的杂事。这个站点是我重写后的版本，目标是：

- **极简**——能不放的东西不放。
- **自适应**——内容在桌面、平板、手机上都能撑满屏幕。
- **好维护**——所有内容是纯 Markdown，未来要加分类、改目录都只需要改一个文件。

## 这个站能做什么

- 📚 教程：把一件事从头到尾讲清楚
- 💬 杂谈：朋友圈风格，记录生活
- 🛤 学习路线：把目标拆成可执行的小段
- 📝 随笔：偶尔的思考
- 🔗 友链：交换链接的地方
- 🔒 我的：私人空间，凭访问码解锁（在导航最右侧）

## 技术栈

- VitePress（静态站点、自动部署到 GitHub Pages）
- Cloudflare Worker（点赞 / 流量）
- disable-devtool（防 F12 调试图文）
- 不蒜子（PV / UV）
