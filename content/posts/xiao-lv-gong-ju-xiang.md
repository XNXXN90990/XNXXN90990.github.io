工具的意义是**减少切换成本**。一年下来换过很多软件，真正留下来的都是开着不烦、离开难受的那几个。

## 记笔记：Markdown 优先

- 本地写作用编辑器 + Markdown，纯文本永不过时
- 需要跨设备同步就用支持 Markdown 的云笔记
- 原则：**笔记是给自己看的**，格式越简单越容易坚持

## 任务管理：一张清单就够

用过 GTD 软件、看板、四象限……最后回归一张清单：

```text
□ 今天必须完成的 1~3 件事
□ 有空再做的备选
✓ 做完的划掉（很有成就感）
```

工具是次要的，**每天花两分钟理一下今天要做什么**才是关键。

## 写代码：顺手就好

| 场景 | 工具 |
| --- | --- |
| 编辑器 | VS Code / JetBrains 系 |
| 终端 | Windows Terminal + Git Bash |
| 版本管理 | Git + GitHub |
| 截图贴图 | Snipaste |
| API 调试 | Apifox / Postman |

## 减法原则

每年我都会做一次「工具断舍离」：连续一个月没打开的，卸载；功能重复的，留一个。桌面清爽了，脑子也清爽。
