## 总览：四个阶段

1. **地基**：HTML + CSS + JavaScript 基础
2. **进阶**：ES6+、异步编程、工程化工具
3. **框架**：Vue 或 React 选一个深入
4. **实战**：做项目、部署上线、持续迭代

## 第一阶段：三件套（约 1~2 个月）

- **HTML**：理解文档结构、语义化标签，知道 `div` 和 `section` 的区别
- **CSS**：盒模型、Flex 布局、Grid 布局、响应式媒体查询
- **JavaScript**：变量、函数、数组与对象、DOM 操作、事件

这个阶段最重要的不是背语法，而是**多动手**：给自己定几个小目标，比如写一个个人介绍页、一个待办清单、一个简单的计算器。

## 第二阶段：现代 JS 与工程化（约 1 个月）

```js
// ES6+ 高频特性
const [a, b] = [1, 2];          // 解构
const arr = [1, 2, 3].map(x => x * 2);  // 箭头函数 + map
async function load() {
  const res = await fetch('/api/data');  // 异步
  return res.json();
}
```

同时了解：`npm` 包管理、模块化（import/export）、Vite 等构建工具的基本使用。

## 第三阶段：选一个框架深入

- **Vue**：模板语法友好，中文资料多，适合入门（本站就是 Vue 3 写的）
- **React**：生态最大，就业市场需求旺盛

框架只是工具，核心还是组件化思维：**把页面拆成一个个可复用的部件**，管理好它们的状态。

## 第四阶段：做项目

学完不练等于白学。推荐三个练手项目，难度递增：

1. 个人博客（就是你现在看到的这个站）
2. 天气/记账小工具（练 API 调用与状态管理）
3. 带登录、增删改查的完整应用（练路由与数据持久化）

做好后部署到 GitHub Pages 或 Vercel，写进简历里比任何证书都管用。

## 学习资源怎么挑

资料在精不在多：官方文档 + 一个系统的视频课 + 大量动手，远胜于收藏夹里躺着的 100 个教程。遇到问题先自己查 20 分钟，再问 AI 或社区，印象会深刻得多。

## 最后

路线是死的，人是活的。卡住了就换个姿势学，做不出就拆小一点做。**持续比速度重要**，祝学习顺利！
