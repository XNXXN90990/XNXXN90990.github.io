## 这个站

- 基于 [AyeezBlog](https://github.com/Ayeez757/AyeezBlog) 开源项目修改而来，感谢[原作者](https://blog.ayeez.cn/)
- 前端 Vue 3 + Vite 部署在 GitHub Pages，配了一套 Spring Boot 后端做内容管理
- 文章分「系列」和「单篇」，密码学与 AI 系列都在持续更新
- 支持深浅色主题切换，也有 [RSS 订阅](/feed.xml) 可以用阅读器追更
